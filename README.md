# Crash Test Simulator (C++ / raylib)

3D-симулятор краш-теста: автомобиль — это **деформируемая сетка из ~195 узлов и ~2300 балок**
(тот же принцип, что в BeamNG.drive). Каждая балка — упруго-пластичная пружина: после предела
текучести она **остаётся смятой** и поглощает энергию, при чрезмерном растяжении — **рвётся**.
Подвеска и шины — отдельная модель (пружина + демпфер + трение шины с кругом сцепления).

## Управление
| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз (на месте — задний ход) |
| A / D | руль |
| Пробел | ручник |
| 1 – 5 | сценарий (машина сразу запускается) |
| R | повторить сценарий |
| ↑ / ↓ | скорость запуска ±5 км/ч (10–160), применяется по R |
| T | замедление 1× / 0.5× / 0.25× / 0.1× |
| H | авто-слоумо в момент удара (вкл/выкл) |
| P | пауза |
| B | вид: кузов / кузов + балки / только балки (цвет = степень смятия) |
| C | цвет кузова |
| F1 | скрыть HUD |
| Мышь | вращение камеры, колесо — зум |

## Сценарии
1. Фронтальный удар в жёсткую стену (100 % перекрытие)
2. Смещённый удар, перекрытие 40 %
3. Лобовой удар в узкий столб
4. Боковой удар в столб (машина боком на «санях»)
5. Свободная езда: стена, столбы, блок

## HUD
Скорость, скорость удара, текущая и пиковая перегрузка (g, фильтр ~100 Гц по центру масс),
смятие спереди и по ширине, энергия пластической деформации (кДж), % повреждённых балок и разрывы.

## Сборка
**Через GitHub (рекомендуется):** залей папку в репозиторий → вкладка *Actions* → *Build* →
в *Artifacts* скачай `CrashTest-windows` (готовый `CrashTest.exe` + папка `assets`).

**Локально:**
```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
Нужен CMake ≥ 3.15 и компилятор C++17. raylib 5.5 скачивается автоматически (нужен интернет).
На Linux нужны пакеты: `libgl1-mesa-dev libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libxkbcommon-dev`.
Папка `assets` (шрифт с кириллицей) должна лежать рядом с exe.

## Проверка физики без окна
```
g++ -std=c++17 -O2 -o physics_test tools/physics_test.cpp
./physics_test 1 56 1.2      # сценарий 1, 56 км/ч, 1.2 с симуляции
```
Типичный результат на 56 км/ч в стену: пик ≈ 43 g, смятие носа ≈ 0.5 м, ≈ 106 кДж ушло в деформацию.

## Настройка «жёсткости» машины
В начале `src/car_sim.h` есть параметры `CS_EA_BASE`, `CS_YC`, `CS_YT`, `CS_ZETA`, `CS_CAGE_MUL`:
жёсткость балок, предел текучести на сжатие/растяжение, демпфирование, прочность салона.
Масса — `carMass`, форма кузова — массивы `topH`, `midH` в `buildCar()`.

## Ограничения (честно)
* Графика low-poly с плоским освещением — это не фотореализм; упор сделан на физику.
* Нет столкновений между двумя машинами и нет самопересечения кузова (при очень сильном
  ударе, > 120 км/ч, детали могут «проходить» друг через друга; от этого защищает минимальная
  длина смятой балки).
* Столб/стена проверяются по узлам сетки, поэтому очень тонкий предмет на огромной скорости
  может частично «прорезать» кузов между узлами.
* Шрифт DejaVu Sans (свободная лицензия, см. `assets/DejaVu-LICENSE.txt`).
